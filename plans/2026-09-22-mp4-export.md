## Shape

| Piece | Where | What |
| --- | --- | --- |
| Clock seam | `engine/clock.ts` (new) | `Clock { now, after, cancel }`; `realClock` (performance.now + setTimeout) and `VirtualClock` (manual time, timers fire in time order at their exact due time) |
| Stage | `engine/stage.ts` | `opts.clock` (default real) replaces every `performance.now()`; `opts.size` fixes the backing size for a detached canvas; `renderAt(now)` = one deterministic frame; `settled` getter. No second renderer |
| Dialect timers | `llm/json-dsl.ts`, `dialect.ts` | `DialectOptions.clock` (optional) for pose/hop "later" commands instead of `window.setTimeout` |
| Replay schedule | `story/replay.ts` | `replaySchedule(events)` = the replayer's capped-gap times; Replayer and exporter share it |
| Audio | `engine/audio.ts` | `StageAudio` interface; `CrayonAudio` takes a seed, `attach(ctx, out, time)` so it can drive an `OfflineAudioContext`; noise from mulberry32, flip n seeded by n. `AudioCues` records `setIntensity`/`pageFlip` with clock time during export; `renderAudioCues()` replays them through a CrayonAudio attached to an OfflineAudioContext |
| Book frame | `export/frame.ts` (new) | canvas drawing of the home screen's storybook (tabletop, coral cover, stitched spine rings, cream paper), "Made by you" tag, page number, the replay's paper caption pill, and the end card |
| Exporter | `export/mp4.ts` (new) | stepper + WebCodecs `VideoEncoder` (H.264, prefer software, 2s GOP) + Mediabunny mux (`EncodedVideoPacketSource` + `AudioBufferSource` AAC/Opus, `BufferTarget`, fast start in memory). Progress callback, AbortSignal, time-budgeted yields |
| UI | `ui/VideoExport.tsx` (new) | button (icon on replay toolbar, studio button on the closing card) + fixed PaperCard with a crayon progress bar and "cancel"; blob → browser download |

## Timeline

- Every record event is scheduled on the VirtualClock at its replay time (`replaySchedule`), so events, dialect timers and frames interleave in exact time order.
- Frame i at t = i·1000/30 ms: `clock.advanceTo(t)` → `stage.renderAt(t)` → compose 1280x800 → `VideoFrame`.
- After the last event: keep stepping until the stage is settled (queue empty, no fx, no bubbles, no page turn), then hold 1.5 s; safety cap 60 s past the last event.
- End card 2 s: 0.35 s crossfade from the last frame to fresh paper with "Made with Once Upon" in the scrawl hand, inside the same book frame.
- Caption = the latest `words` chunk at or before t (what the replay's caption pill shows), drawn as the pill near the top of the paper.

## Layout (1280x800)

Tabletop `#eee5d5` + seeded grain; book cover rect x 22..1254, y 18..780, coral `#d9937e`, 2px `#876351` edge, radius 17/23, hard offset shadows `#c4b59e`/`#d9ccba`; spine 36px with five rings (`#f9dbbf`/`#a66c55`); paper at (60, 28) 1184x740 (exactly 16:10, so the 160x100 world fills it, S = 7.4), radius 7/16/15/6. Values mirror `.storybook` / `.book-binding` / `.story-paper` in app.css.

## Determinism

No Math.random anywhere in the path (audio noise moved to mulberry32). Virtual clock starts at 0. Same record → same frames → same encoder input; the mp4 differs at most in muxer/encoder timestamps.

## Seam for the child's voice

`exportStoryVideo(record, { voice })` where `voice: VoiceTrack = { mix(ctx: OfflineAudioContext, videoTimeOf: (recordMs) => number): void }`. Nothing records voice yet.
