**Decisions already made.**
- Schema: `Device.aiConsentAt DateTime?` (null = no consent). Nothing else changes shape except what V-21/V-22 need (an `AdminAudit` row kind if one is missing). The predeploy stays `prisma db push` (the lead drops `--accept-data-loss` in Drydock); every schema change must be additive.
- Consent (V-20, decision 8): `device.consent` sets each field present (`aiConsent: true` → `aiConsentAt = now()`, `false` → null; `shareVoice` keeps today's paying-only rule). `DeviceState.aiConsent = aiConsentAt != null`. `session.start`, `session.typed` and `POST /api/app/draw` answer 403 `{error:{code:'consent_required'}}` (draw: the NDJSON line `{"k":"error","code":"consent_required",...}` if the stream has started, else the 403) when it is null. All platforms.
- Free minutes and quiet time (decisions 1, 2): flag defaults `freeFirstStorySec` 300, weekly 180 (Saturday, as today), `silenceNudgeMs` 30000, `silenceEndMs` 60000. Existing devices keep their balance. Write in your report which flags are DB-overridable so the lead can check production's overrides.
- No charge for failed drawing (V-05, M7, S-13 server half): a typed message whose draw fails (CallLog error, or no completed call for the session within 20 s of the typed charge) is refunded as a ledger credit `refund_failed_draw`; a beat window in which every relay call failed or none completed charges 0. `freeStoryUsed` flips only after the first successful draw. Pick the mechanism; keep it in sessions.ts / relay.ts / ledger.ts.
- Relay (V-03, V-06, V-07, V-10, V-11, V-01): user blocks `.max(100)`, total user chars ≤ 40,000, `maxTokens` ≤ 1600. The server owns the prompt: accept `system` only if it is one the studio's shipped dialects (kit, sketch) produce, else 400 `bad_request` "unknown prompt" (allow-list by sha256 built from the studio's own prompt builders at boot or build; your choice, but it must not drift when the prompt is edited in `src/llm`). One draw in flight per device (a second gets 429 `cap`; the studio never has two). Reserve `maxTokens` × output price when checking the per-device cap; on abort estimate output tokens as `chars / 3`. One module-level Anthropic client `{ maxRetries: 1, timeout: 20_000 }`; a 6 s first-token deadline that ends the stream with `{k:'error', code:'upstream', message:'slow'}`. Abort upstream on `res.on('close')` and prove it with a local test. Refuse a draw (429 `cap`) when the session has made more than 12 calls per charged minute + 3 grace; run the stale-session close every minute.
- Global spend stop (V-08): new flag `dailySpendStopCents` default 7500. Above it (60 s cached aggregate of today's UTC CallLog cost) the relay refuses non-paying, non-comped devices with 503 `paused` and raises an alert once per day. Alert checks every 10 minutes, UTC day everywhere (V-32).
- Cloud ears (V-09): flag `cloudEars` default false. When false, and always for `platform: 'ios'`, `session.start` returns `ears: null` and `ears.token` answers 403 `blocked`.
- Registration and rate limits (V-02, V-29): in-memory per-IP limits (client IP = first `X-Forwarded-For` hop, Caddy sets it; else the socket): `device.register` 10/hour; `/api/app/*` except draw 300/min; `share.create` 20/hour; `shop.checkout`, `gift.checkout`, `gift.redeemOnWeb` 10/min. Over the limit: 429 `cap`. Shares also 20 per device per day (V-25).
- Money: V-04 conditional updates; V-14 at boot in production build the Production `SignedDataVerifier` and, if it throws, log an error and send the alert email (do not refuse to start); V-15 write StripeEvent inside the fulfillment transaction; V-17 `gift.redeem` from `platform: 'ios'` → 403 `blocked`; V-18 revenue queries filter `environment = 'Production'`.
- Privacy (V-21, V-22, V-24): admin "Delete device" on the device page in /admin: confirm step, cascade delete, an audit row with the device code and row counts. Daily retention job: `CallLog.skipWords` → null after 30 days; CallLog and StorySession rows deleted after 180 days; AppleNotification payloads deleted after 180 days; devices with balance 0, not comped, idle 18 months deleted. tRPC `onError` logs path and code only.
- Admin signup (V-28): better-auth `disableSignUp: true` unless env `ADMIN_SIGNUP=open`. The lead checks both admin accounts exist before this deploys.
- Legal pages app mode (V-27, R4): `?app=1` on `/privacy`, `/terms`, `/support`, `/delete-my-data` renders the page with no site nav, no footer, no links to shop, gift, pricing or "Get the app". `ClientConfig` `privacyUrl`, `termsUrl`, `supportUrl`, `deleteDataUrl` carry `?app=1`. Delete the theme script in `apps/web/index.html` (one theme). The legal copy itself is the lead's; don't edit the text of privacy.tsx / terms.tsx / support.tsx / delete-data.tsx beyond the app-mode wrapper.
- Tests (V-33): `bun test` in apps/web against DB `onceupon_srv` with a mocked Apple verifier: consent refusal, refund on a failed draw, V-03 block limit, V-14 boot check, V-15 retry credits once, the per-device in-flight limit, the spend stop. Add `"test"` to apps/web package.json if missing.
