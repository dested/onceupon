Assumptions

Anthropic list prices from the repo's pricing table (Sonnet 5: $2 in, $10 out, cache read $0.20, cache write $2.50 per MTok). System prompt is a cached read every call (about 6,000 tokens Ops as measured, 5,300 JSON, 4,200 Lines). Each beat sends the scene snapshot and a ~150-token header uncached, writes the new ~30 words to cache, and reads the story-so-far from cache (grows with session length). Output tokens per beat: the measured preset is the Sep 22 session average (~150 on Ops; beats ranged 34 to 352); the conservative preset is the dense opening two sentences (942 tokens for two beats on Ops, 3,164 on JSON ops); Lines measured ~200 on Haiku. Restarts bill input plus 100 output tokens. Put fresh numbers from the debug panel into the sliders as the prompts change.

Speech prices, September 2026: OpenAI transcription (gpt-live-transcribe and realtime whisper $0.017/min; gpt-4o-transcribe $0.006; gpt-transcribe $0.0045 file only), Deepgram (Nova-3 streaming $0.0077 list, $0.0048 promo; Flux $0.0065 promo), AssemblyAI (Universal-Streaming $0.15/hr).
